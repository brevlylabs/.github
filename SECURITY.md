# Security Policy

## Supported Versions

Currently, Brevly is a managed SaaS platform. We support and actively patch the live production environment.

## Reporting a Vulnerability

We take the security of our platform and our users' data very seriously. 

If you discover a security vulnerability within the Brevly ecosystem (API, Bot, Web Dashboards, or Infrastructure), **please do not disclose it publicly by opening an issue.**

Instead, please report it privately to our security team by emailing:

📧 **security@brevly.app**

### What to include
Please provide as much information as possible to help us understand and reproduce the issue:
- A description of the vulnerability.
- The specific URL, API endpoint, or Telegram Bot command where the vulnerability exists.
- Step-by-step instructions on how to reproduce it.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress.
