# Support

Need help with Brevly? We've got you covered.

**Because the Brevly repositories are closed-source, we do not use GitHub Issues for general customer support.** 

Please use the following resources depending on your needs:

## For Organizers 
If you are managing a brevet and need help with the Organizer Hub, billing, or event configuration:
*   **Documentation:** [docs.brevly.app](https://docs.brevly.app)
*   **Email Support:** `support@brevly.app`

## For Riders
If you are participating in a brevet and having trouble registering, checking in, or using the Telegram Bot:
*   **FAQ:** Please consult the help section within your Rider Dashboard (`web.brevly.app`).
*   **Contact your Organizer:** In most cases, during an active event, you should contact the specific event organizer directly.
*   **Platform Issues:** If the Telegram bot is completely unresponsive, email `support@brevly.app`.

## Feature Requests & Bug Reports
If you have discovered a bug in the software or want to request a new feature:
*   Please email `hello@brevly.app` with the details. 
*   If reporting a bug, please include screenshots and your device information if possible.
